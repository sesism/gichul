개인정보처리방침

기출 모의고사 (https://sesism.github.io/gichul/)

1. 수집하는 정보

이 앱은 운영자의 서버로 어떤 개인정보도 보내거나 수집하지 않습니다. 사용자가 등록한 문제 이미지, 정답, 풀이 기록은 사용자의 기기(브라우저 저장소) 안에만 저장됩니다.

2. 구글 드라이브 연동

사용자가 구글 드라이브 백업을 연결하면, 앱은 구글의 drive.file 권한으로 사용자의 구글 드라이브에 ‘기출모의고사 백업’ 폴더와 백업 파일을 만들고 읽습니다. 이 권한으로는 앱이 직접 만든 파일에만 접근할 수 있으며, 사용자의 다른 드라이브 파일은 볼 수 없습니다.

백업 파일은 사용자 본인의 구글 드라이브에만 저장되며, 운영자를 포함한 다른 누구에게도 전송되지 않습니다. 로그인 정보(액세스 토큰)는 사용자의 기기에만 잠시 보관됩니다.

3. 정보의 삭제

앱의 ‘연결 끊기’를 누르면 구글 드라이브 접근 권한이 해제됩니다. 기기에 저장된 데이터는 앱(홈 화면 아이콘)을 삭제하거나 브라우저의 사이트 데이터를 지우면 삭제되고, 드라이브의 백업 파일은 사용자가 드라이브에서 직접 삭제할 수 있습니다. 구글 계정의 보안 설정(서드 파티 앱 및 서비스)에서도 언제든 권한을 해제할 수 있습니다.

4. 문의

이 앱은 개인 학습용으로 만들어졌습니다. 문의는 구글 클라우드 동의 화면에 등록된 이메일로 해주세요.
